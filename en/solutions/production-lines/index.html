What changes

The same work, before and after the line.

Today
  • Machines from different suppliers that do not talk to each other.
  • Parts wait between stations; work in progress piles up.
  • When output falls short, each supplier points to another.
With an automated line
  • A line PLC coordinates handling between stations.
  • Handling between stations, with inspection built in.
  • One contract and one acceptance test for the whole line.
